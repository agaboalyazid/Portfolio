Largest Banks ETL Pipeline

An end-to-end Python ETL job: extract from a web page, convert currencies, load to file and database, and log every step.

01Overview

The pipeline reads the list of the world's largest banks from an archived Wikipedia page, converts market capitalisation from USD into GBP, EUR and INR, and stores the result in a CSV file and a SQLite database for querying.

02What I built

  • extract(): parses the archived page with Requests and BeautifulSoup into a DataFrame
  • transform(): cleans the values and converts USD to GBP, EUR and INR from an exchange-rate file
  • load_to_csv() and load_to_db(): write the result to CSV and to a SQLite table
  • run_query() and log_progress(): query the table and timestamp every stage in a log file
